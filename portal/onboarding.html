🚀 시작 가이드

내 PC에 개발 환경을 구축하고 Claude Code를 사용하는 전체 과정입니다. 순서대로 따라 하시면 됩니다.

준비물 — 본인 PC(Windows 또는 Mac), 본인 Google 계정, 강사가 보낸 Claude Team 초대 메일과 GitHub Organization 초대.

STEP 1. 기본 프로그램 설치

  1. Node.js LTS 설치 — nodejs.org에서 LTS 버전 다운로드
  2. Git 설치 — git-scm.com
  3. VS Code 설치 — code.visualstudio.com

설치 확인 (터미널 / Windows는 PowerShell):

node -v
git --version
Windows 사용자 — 가능하면 WSL2(Ubuntu) 환경 사용을 권장합니다. Claude Code와 개발 도구가 더 안정적으로 동작합니다. 설치가 어려우면 강사에게 문의하세요.

STEP 2. Claude Code 설치

npm install -g @anthropic-ai/claude-code

설치 확인:

claude --version

STEP 3. 본인 계정으로 로그인 (Claude Team)

  1. 강사가 보낸 Claude Team 초대 메일을 수락합니다 (본인 Google 계정으로).
  2. 프로젝트 폴더를 하나 만들고 그 안에서 claude 를 실행합니다:
mkdir my-project
cd my-project
claude
  1. 표시되는 로그인 URL을 브라우저에서 열고 본인 Google/Claude 계정으로 로그인합니다.
  2. 로그인이 완료되면 Claude Code를 사용할 준비가 끝납니다.
인증 정보는 본인 PC에만 저장됩니다. 다른 사람과 계정을 공유하지 마세요.

STEP 4. GitHub 저장소 연결

  1. 강사가 보낸 GitHub Organization 초대를 수락합니다.
  2. 본인 프로젝트 저장소(예: aiclaude-edu/student01-project)를 clone 합니다:
git clone https://github.com/aiclaude-edu/studentXX-project.git
cd studentXX-project
  1. 작업 후에는 매일 push 하는 습관을 들이세요 (자동 백업 + 진척 관리):
git add .
git commit -m "오늘 작업 내용"
git push

STEP 5. 결과물 배포 → 포털에 공유

완성한 프로젝트는 무료 호스팅으로 배포하고, 그 링크를 진행 현황 페이지에 등록합니다(강사에게 전달).

  • 정적 사이트 (React/Vue 빌드 등): GitHub Pages, Cloudflare Pages
  • 풀스택/SSR: Vercel, Netlify (무료 티어)

자세한 배포 방법은 강의 자료의 배포 가이드를 참고하세요.

문제가 생기면?

  • claude 명령이 안 될 때 → Node.js가 제대로 설치됐는지 node -v 확인
  • 로그인이 안 될 때 → Claude Team 초대를 수락했는지 확인
  • 그래도 안 되면 → 담당 강사에게 화면 캡처와 함께 문의
