교육 진행 방식

서버는 포털만 담당하고, 개발은 각자 PC에서 이뤄집니다.

1

내 PC에 환경 구축

Node.js · Git · VS Code · Claude Code를 설치하고 본인 Google/Claude Team 계정으로 인증합니다.

2

Claude Code로 개발

각자 프로젝트를 Claude Code와 함께 만들어 나갑니다. 빌드와 실행은 모두 내 PC에서.

3

GitHub로 관리

매일 작업을 본인 GitHub 저장소에 push 합니다. 자동 백업 + 진척 관리가 됩니다.

4

포털에 배포·공유

완성한 결과물을 무료 호스팅으로 배포하고, 이 포털 진행 현황에 링크를 등록합니다.
